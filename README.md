# Android Semar
![logo](logos.png)
Aplikasi Android untuk mengakses SEMAR

## persyaratan sistem:
- Android 6 keatas
- Gawai berarsitektur ARMv7 atau ARMv8
- RAM 1GB
- Ruang Penyimpanan sebesar 20MB
- Kapabilitas Wi-Fi

Untuk penjelasan mengenai SEMAR lebih lengkap kunjungi https://github.com/attar-sanjaya/semar
